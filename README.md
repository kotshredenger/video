# Universal Player

Видеоплеер для Android на движке **libVLC** — открывает практически любые форматы:
MP4, MKV, AVI, MOV, FLV, WebM, TS, WMV, 3GP, MPEG, HEVC/H.265, VP9 и многие другие,
а также сетевые ссылки и потоки (HTTP/HTTPS, HLS, RTSP).

## Возможности

- Перемотка: ползунок, кнопки ±10 с, двойной тап слева/справа, свайп по горизонтали
- Пауза/пуск (кнопка, двойной тап по центру, пробел / медиа-клавиши)
- Скорость 0.25x – 4x
- Выбор звуковой дорожки и субтитров, загрузка внешних субтитров (.srt, .ass и др.)
- Задержка звука и субтитров, усиление громкости до 200%
- Соотношение сторон: вписать, подогнать, растянуть, 16:9, 4:3, оригинал
- Яркость (свайп вверх/вниз слева) и громкость (свайп справа)
- Блокировка экрана, поворот экрана, таймер сна, повтор
- Аппаратное / программное декодирование (при ошибке переключается само)
- Запоминает позицию просмотра и историю
- Открывается из файловых менеджеров и по ссылкам («Открыть с помощью»)

## Как получить APK через GitHub

1. Создайте новый репозиторий на github.com.
2. Загрузите в него **всё содержимое** этой папки (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** → workflow **Build APK** (запустится сам после загрузки,
   либо нажмите **Run workflow**).
4. Через 5–10 минут откройте завершённый запуск и скачайте **UniversalPlayer-apk** из раздела Artifacts.
5. Распакуйте архив и установите `UniversalPlayer-release.apk` (или `-debug.apk`) на телефон.
   Может понадобиться разрешить установку из неизвестных источников.

Чтобы APK появился на странице Releases: создайте тег вида `v1.0`.

## Сборка локально

Нужны JDK 17 и Android SDK: `gradle assembleRelease`
(или откройте папку в Android Studio).
